## Publish with GitHub Pages
1. Sign in to GitHub as `williamsidoro`.
2. Open https://github.com/new
3. Repository name: `education-sponsorship`.
4. Set visibility to **Public**. Do not initialise with extra files if you intend to upload this package exactly as supplied.
5. Click **Create repository**.
6. Open the new repository. Choose **Add file → Upload files**.
7. Extract this ZIP on your computer. Open the extracted `education-sponsorship` folder and upload its contents (the files themselves) into the repository root. `index.html` must be at the root, not inside another nested folder.
8. Commit the upload to the `main` branch.
9. Go to **Settings → Pages**.
10. Under **Build and deployment**, select **Deploy from a branch**.
11. Select branch `main` and folder `/(root)`, then click **Save**.
12. Wait for deployment. Check the repository's **Actions** tab or Pages settings for status.
13. Visit `https://williamsidoro.github.io/education-sponsorship/`.

## Donation safety — leave disabled for now
The donation button is deliberately disabled. Activate it only after a payment provider expressly approves this personal education fundraiser, verifies your identity and Nigerian payout arrangement, and provides the exact official HTTPS checkout URL. Check fees, payout timing, country eligibility, donor restrictions and refund terms.

Then edit `config.js`, replacing the empty string with the exact official provider URL. Never guess a URL or publish personal bank details.

- Confirm current tuition, scholarship and admission status.
- Replace the £50,000 ambition with an itemised, sourced budget.
- Check current UK Student visa financial-evidence rules directly with official UKVI guidance. Crowdfunding proceeds, donor promises and sponsorship letters are not automatically qualifying visa evidence.
- Check the biographical statements for accuracy.
- Do not claim registered charity/foundation status, tax deductibility, guaranteed admission or guaranteed visa approval.

## Security
GitHub Pages is static hosting. It does not securely process card payments or store private donor records. Never upload passport scans, bank statements, account numbers, passwords, API keys, access tokens or confidential donor information to this public repository.

This is a personal education sponsorship campaign, not a registered charity. Contributions are not represented as tax-deductible charitable donations.
